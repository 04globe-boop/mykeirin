# keirin-odds-logger

競輪の締切前オッズを、全競輪場・全レースについて決まった時点で記録する。

## 仕組み
- GitHub Actions が JST 7:00〜24:59 の間、10分おきに `logger/run_logger.py` を起動する。1回の起動は約12分動く。
- データ元は netkeirin の内部API（`https://keirin.netkeiba.com/api/race/`）。1レース1回の通信で全券種のオッズが取れる。
- 取得する時点（締切からの分）：-60, -30, -20, -15, -10, -7, -5, -3, -2, -1、締切後 +8（確定値の確認）。
- -60 と -5 では、並び予想（ライン区切り付き）と出走表も取り、直前の変更（並びの変更、欠車）を追跡する。
- 起動が遅れて予定時刻を過ぎた場合、許容範囲（締切3分前以内は45秒、10分前以内は2分、それより前は5分）なら取り直し、超えたら `miss` として記録する。推測で埋めない。

## 保存先
- 記録はリポジトリ本体ではなく Releases に置く（リポジトリの肥大化を防ぐため）。
- リリース `odds-YYYY-MM` に、開催日ごとのファイル `odds_YYYYMMDD.jsonl.gz` を置く。
- 1行1レコードのJSON。`type` は racelist / odds / lines / entries / miss / error。
  - `odds.data.list_3`〜`list_9` = 2枠複, 2枠単, 2車複, 2車単, ワイド(下限,上限), 3連複, 3連単。各要素は `[組番, オッズ, ワイド上限, 人気順]`
  - `fetched_at` は実際に取得した時刻、`target_at` は予定時刻（どちらもJST）
  - `lines.parsed` はラインごとの車番の並び（例 `[["5","3"],["8","7","1"],["6","2","4"]]`）
